Fast API client for iPhone and iPad. Send REST requests, test auth and headers, inspect JSON responses, and organize endpoints in collections. Relay is a modern API client and REST client built for iPhone and iPad. Send HTTP requests, inspect responses, and manage API workflows from anywhere. What you can do with Relay: - Send requests with common HTTP methods (GET, POST, PUT, PATCH, DELETE, and more) - Build requests with query parameters, headers, body, and auth - Test Bearer Token, Basic Auth, and API Key configurations - Inspect response body, headers, and request timing details - Validate and format JSON for faster debugging - Import cURL commands to quickly recreate terminal requests - Organize endpoints in collections and folders - Use environments and variables to switch between dev, staging, and production - Re-run requests from history to speed up testing Relay Pro unlocks advanced workflow and organization features for power users. You can start testing APIs immediately, with no account required. If you build, test, or debug APIs, Relay is the HTTP client that fits your iPhone and iPad workflow.
